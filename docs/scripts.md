# Scripts

Every file under `scripts/` is a plain Node.js ES module (or a SQL fixture). None of them reads credentials from the repository: anything that touches Cloudflare takes its token from the environment in a GitHub Actions job. Run them from the repository root.

## Conventions

- Scripts exit non-zero with a one-line reason. They do not prompt.
- Temporary D1 state goes to `os.tmpdir()` and is removed in a `finally` block; nothing is written into `.wrangler/` except by `setup.mjs`, which targets the developer's own local database on purpose.
- New scripts get an npm alias in `package.json` when developers are expected to run them, and a row in this table either way.
