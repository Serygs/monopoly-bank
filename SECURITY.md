# Security Policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues or pull
requests. Use this repository's private vulnerability-reporting channel at
**Security → Advisories → Report a vulnerability**. Include reproduction
steps, impact, and any suggested mitigation.

If private reporting has not been enabled yet, contact the repository owner
privately and do not disclose the vulnerability publicly until a fix is
available.

## Scope notes

Never include passwords, session cookies, invitation tokens, avatar data, API
tokens, Cloudflare credentials, or production data in a report.
